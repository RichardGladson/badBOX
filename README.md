# Badbox

**One box. Two worlds.**

Badbox is an all-in-one ESP32 handheld platform that brings together portable gaming and wireless security research in a single hardware ecosystem.

Built around two distinct projects, Badbox combines the playful side of handheld gaming with the technical side of wireless experimentation.

## Projects

- 🎮 **Flipbox** — A portable gaming project focused on custom games and handheld entertainment.
- 📡 **Doombox** — A portable wireless research device built for experimentation and cybersecurity-related projects.

Each project maintains its own firmware, features, and documentation.

## Repositories

- [Flipbox](https://github.com/RichardGladson/Flipbox)
- [Doombox](https://github.com/RichardGladson/doomBOX)

## About

Badbox brings both projects under one umbrella, providing a unified starting point for exploring the hardware and its different capabilities.

For detailed features, hardware requirements, setup instructions, and firmware flashing, refer to the respective project repositories.
